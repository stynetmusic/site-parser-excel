# Site Parser to Excel

Учебная программа IT-мастерской Stynet. Она читает открытый каталог [Books to Scrape](https://books.toscrape.com/) и сохраняет книги в файл Excel.

Проект сделан для учебной практики и портфолио. Это не заказ для настоящего магазина и не универсальный парсер любых сайтов. Цены и рейтинги на Books to Scrape демонстрационные.

Программа берёт с карточки название, цену, рейтинг, наличие и ссылку, открывает страницу книги за количеством экземпляров и записывает два листа: «Каталог» и «Сводка». Пропущенное поле остаётся пустым. Причина пишется в журнал, значение не выдумывается.

Полный сбор завершается с кодом 0. Ошибка или неполный сбор завершаются с кодом 1.

## Возможности

- Обход страниц каталога и страницы каждой книги.
- Цена сохраняется числом, валюта — отдельным кодом. Для строки `£51.77` это `51.77` и `GBP`. Подходит и `£0.00`.
- Рейтинг переводится из CSS-класса `One` … `Five` в число от 1 до 5.
- Количество экземпляров читается только со страницы книги, например из `In stock (22 available)`.
- В Excel есть автофильтр, закреплённая строка заголовков и числовой формат цены. Ссылка на книгу открывается из ячейки, если адрес разрешён.
- Текст с сайта, который начинается с `=`, `+`, `-` или `@`, записывается как текст, а не как формула Excel.
- Символы, недопустимые в XML Excel, удаляются. Обычные буквы Unicode, включая кириллицу, сохраняются. Если символы удалены, в журнал пишется предупреждение.
- Файл сначала сохраняется во временный файл в той же папке и заменяет цель через `os.replace`. При сбое записи прежний отчёт остаётся на месте.

Неподходящая цена не превращается в положительное число. Не подходят `£-1.20`, `-£1.20`, `£−1.20`, `£–1.20`, `(£1.20)` и `£1,234`. Запятая не считается десятичным разделителем. Строка `51.77` без знака валюты сохраняет число, а код валюты оставляет пустым.

## Технологии

- Python 3.10 или новее. В коде используются записи вида `str | None`.
- [requests](https://pypi.org/project/requests/) — загрузка HTML.
- [BeautifulSoup4](https://pypi.org/project/beautifulsoup4/) — разбор страниц.
- [openpyxl](https://pypi.org/project/openpyxl/) — файл Excel.
- [pytest](https://pypi.org/project/pytest/) — тесты.

Остальное берётся из стандартной библиотеки Python: командная строка, журнал, пути, разбор URL. Версии прямых зависимостей зафиксированы в `requirements.txt`. В комментарии к этому файлу указано, что они проверялись на Python 3.14.

Имя клиента при запросе: `SiteParserExcel/1.0 (educational portfolio; demo catalog only)`.

## Требования

Нужен Python 3.10 или новее и доступ в интернет для запуска по живому сайту. Тесты сеть не используют.

Зависимости ставятся из `requirements.txt`:

- `requests==2.34.2`
- `beautifulsoup4==4.15.0`
- `openpyxl==3.1.5`
- `pytest==9.2.0`

## Установка

Команды выполняются в папке проекта. Если путь содержит пробелы, возьмите его в кавычки.

macOS и Linux:

```bash
cd site-parser-excel
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows в командной строке, если `python` доступен:

```bat
cd site-parser-excel
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

В PowerShell активация другая:

```powershell
.\.venv\Scripts\Activate.ps1
```

## Запуск

Справка показывает фактические параметры:

```bash
python -m books_parser --help
```

Полный обход каталога. Без `--max-pages` действует предел 200 страниц. Если каталог закончился раньше и следующей страницы нет, программа записывает `output/books_catalog.xlsx` и завершается с кодом 0.

```bash
python -m books_parser
```

Одна или две страницы на Books to Scrape не закрывают каталог: следующая страница ещё есть. Такой запуск неполный, код выхода 1. Основной файл не заменяется. Уже собранные книги пишутся в соседний файл с `.partial` перед расширением.

```bash
python -m books_parser --max-pages 1
python -m books_parser --max-pages 2 --output output/sample.xlsx
```

Первая команда создаёт `output/books_catalog.partial.xlsx`. Вторая создаёт `output/sample.partial.xlsx` и не заменяет уже существующий `output/sample.xlsx`.

Значения по умолчанию можно указать явно:

```bash
python -m books_parser --delay 0.5 --timeout 15 --attempts 3 --log-file logs/parser.log --start-url https://books.toscrape.com/
```

Параметры:

| Параметр | Короткий вид | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `--max-pages` | `-n` | предел 200 | Сколько страниц каталога обработать. Число меньше 1 отклоняется. Число больше 200 ограничивается 200. |
| `--output` | `-o` | `output/books_catalog.xlsx` | Куда сохранить полный отчёт. |
| `--delay` |  | `0.5` | Пауза между запросами в секундах. Меньше `0.2` указать нельзя. |
| `--timeout` |  | `15` | Сколько секунд ждать ответ. |
| `--attempts` |  | `3` | Сколько раз повторять временную ошибку загрузки. |
| `--start-url` |  | `https://books.toscrape.com/` | Первая страница. Принимается только разрешённый адрес. |
| `--log-file` |  | `logs/parser.log` | Файл журнала. |

После полного запуска в консоли видны число страниц, число книг, наличие, средняя цена, средний рейтинг и путь к файлу. Подробности пишутся в журнал.

Если первая страница не открылась из-за сети, программа завершается с кодом 1 и новый Excel не создаёт. Если страница открылась, но карточек книг нет, файл тоже не создаётся: это ошибка структуры, а не пустой успешный каталог.

## Результат

Полный отчёт — файл из `--output`. По умолчанию это `output/books_catalog.xlsx`.

Неполный сбор с уже найденными книгами пишет отдельный файл. Имя строится из заданного пути: `books_catalog.xlsx` становится `books_catalog.partial.xlsx`, `output/sample.xlsx` — `output/sample.partial.xlsx`. Основной файл при этом не перезаписывается. Если книг нет, новый файл не создаётся.

Лист «Каталог»:

- Название, Цена, Валюта, Рейтинг, Наличие, Количество, Ссылка;
- закреплённая первая строка и автофильтр;
- цена в числовом формате;
- ссылка становится гиперссылкой только для адреса, который прошёл ту же проверку, что и запросы парсера.

Лист «Сводка»:

- дата и время сбора;
- обработано страниц;
- найдено книг;
- книг в наличии;
- книг нет в наличии;
- средняя цена;
- средний рейтинг.

Средние считаются только по книгам, где цену или рейтинг удалось прочитать. Книга с неизвестным наличием не входит ни в одну из двух групп наличия. Если на странице написано `Out of stock` и число не указано, программа не подставляет ноль.

## Тестирование

Тесты читают `tests/fixtures/`, подменяют HTTP-запросы и пишут Excel во временные каталоги. К сайту они не обращаются.

```bash
python -m pytest -q
```

Проверяются поля книги, пустые значения, сеть, запрещённые адреса, редирект, ответы 403 и 429, предел страниц, файл Excel и сводка.

## Ограничения и безопасность

Парсер открывает только `https://books.toscrape.com`: точное имя сайта, схема HTTPS, без логина и пароля. Порт можно не указывать или указать 443. Запрещены другой сайт, `http://`, `localhost`, IP-адрес, адрес локальной сети и нестандартный порт. Пустая секция авторизации, например `https://@books.toscrape.com/`, тоже запрещена.

Проверка выполняется до запроса для начального адреса, ссылки на книгу и ссылки на следующую страницу. `urljoin` только собирает относительный адрес и сам разрешение не даёт. `--start-url` принимает только такой адрес. Встретив запрещённую ссылку, программа её не открывает и останавливает обход.

Ответы 301, 302, 303, 307 и 308 не выполняются. Программа не запрашивает `Location`, в том числе если перенаправление вернулось бы на тот же сайт.

Ответы 403 и 429 останавливают весь обход сразу. Повтора нет, следующие книги и страницы не запрашиваются, код выхода 1. Если книги уже собраны, они попадают только в файл `.partial`. Если книг нет, файл не создаётся.

Ответ 401 не повторяется и не обходится, но не останавливает остальные запросы так же, как 403 и 429. Ответ 404 не повторяется. Повторяются временные ошибки и HTTP-статусы 408 и 500 и выше, кроме 429, который останавливает обход без повтора. Число попыток задаёт `--attempts`.

Пять неудачных загрузок страниц книг подряд останавливают сбор. Успешная страница книги сбрасывает этот счётчик. Коды 403 и 429 от счётчика не зависят.

Если `--max-pages` не указан, предел — 200 страниц. Меньшее значение используется как есть. Большее ограничивается 200. Когда предел достигнут, а следующая страница каталога есть, сбор неполный. Если каталог закончился раньше, запуск полный.

Программа не входит в учётные записи, не решает CAPTCHA и не обходит ограничение доступа. Сторонним сервисам она ничего не отправляет. Если процесс прервать во время записи, в папке может остаться временный файл `.имя.xlsx.*.tmp`. Готовый отчёт при этом не затирается наполовину.

Разбор зависит от текущей вёрстки Books to Scrape. Если разметка изменится, поля могут перестать находиться.
